# 网页字段地图（M0 已核验 + 权限更新）

依据 2026-08-03 提供的 Edge 截图及权限更新截图核验。页面锚点为“科技项目管理系统 信息版”与“专利信息库”；证书字段与网页可编辑权限分开记录。未由证书、人员主数据、项目台账或用户明确提供的字段一律不猜填。

## 证书驱动的更新字段

| 网页字段 | 证书来源/转换规则 | 更新及验证规则 |
|---|---|---|
| 专利号 | `patent_no` 移除 `ZL` 和小数点，保留末位数字或 `X` | 例如 `ZL201810637498.0` 填为 `2018106374980`；回读输入框核验 |
| 申请名称 | `title` | 全量替换后回读核验 |
| 专利状态 | 当前页固定选项“授权” | 仅在当前值不是“授权”时选择；回读选项文本 |
| 申请类型 | `patent_type` 映射“发明”或“实用新型” | 仅勾选对应的一项；验证另一项未选中 |
| 申请受理日 | `application_date` | 按 `YYYY-MM-DD` 输入；截图样本与证书申请日一致 |
| 授权公告日 | `grant_publication_date` | 按 `YYYY-MM-DD` 输入并回读 |
| 专利权人表 | `current_patentees`，保持证书顺序 | 截图已确认新增/删除控件；逐条填充并核对行数和顺序；默认不删除已有行 |
| 第一发明人 | `inventors[0]` | 通过人员选择器匹配姓名；只在唯一匹配时写入 |
| 发明人表 | `inventors`，保持证书顺序 | 逐条填充并读取表格末行验证；姓名不唯一则暂停 |
| 专利权人合并 | 由已核对的权利人表派生 | 截图显示可编辑；只在表格核验成功后写入并回读，不独立猜填 |
| 发明人合并 | 由已核对的发明人表派生 | 截图显示可编辑；只在表格核验成功后写入并回读，不独立猜填 |

## 明确排除或保持原值的字段

| 网页字段/区域 | 处理方式 | 原因 |
|---|---|---|
| 申请号 | 不更新 | 截图示例 `00923` 是内部编号，证书没有该值 |
| 所属机构、申请部门、专利单位 | 保持页面已有值 | 不能从证书推出 |
| 是否联合申请、联合申请说明 | 不更新 | 当前截图不足以确认复选/下拉的业务口径 |
| 交付日、授权通知日、业务领域、代理机构 | 保持原值或留空 | 证书没有对应信息 |
| 第一发明人身份证号、联系方式 | 不更新 | 属于人员主数据，证书未提供 |
| 技术摘要、提高效率/可靠性/降低能耗 | 人工或说明书/业务模板；自动化默认跳过 | 截图已确认可编辑，但证书不提供 |
| 技术/工程项目名称、编号、所属单位、其他 | 项目台账或人工填写 | 截图已确认输入框存在，不使用证书字段代替 |
| PCT 数量 | 人工选择或业务规则 | 截图已确认下拉框存在；选项语义和默认值待确认 |
| 经办人、手机、邮箱 | 本地配置或人工填写 | 截图已确认输入框存在；写入后回读并脱敏 |
| 补充附件、受理附件、授权通知附件 | 不上传、不删除 | 页面已提供证书“预览/下载”；附件自动化移至后续功能 |

## 执行边界

1. 首版以 Edge 为唯一受支持浏览器；其他浏览器待现场验证后再纳入支持矩阵。
2. 先识别页面锚点和字段标签，再按锚点相对位置操作；禁止用全局固定坐标。
3. 每个更新字段写入后立即截屏或 OCR 回读验证；页面、窗口或焦点变化时暂停。
4. 程序完成所有可确认字段的核验后停在“保存”前，由用户检查并手动保存。

## 权限更新证据与执行边界

1. 三张截图显示技术摘要“编辑”入口、预期效益文本框、专利出处/项目关联字段、动态表格新增/删除、第一发明人选择入口、身份证号/联系方式、PCT 下拉和经办人字段。
2. “可编辑”只代表当前账号看到了编辑控件；字段值来源和业务必填规则仍需配置或人工确认。
3. 自动化可以在 M2/M3 中识别和回读这些控件，但 M1 不生成非证书字段；正式流程仍停在“保存”前。
