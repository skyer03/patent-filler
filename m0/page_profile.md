# Edge 页面 Profile v2（权限更新）

## 页面锚点

- 顶部系统标题：`科技项目管理系统 信息版`
- 模块标签：`专利信息库`
- 首个区块：`基本信息`
- 后续区块：`技术摘要`、`预期效益`、`专利权人/发明人`、`专利出处`、`经办人`、`附件`
- 页面顶部操作：`保存`、`返回`

自动化必须同时识别模块标签、当前区块标题和目标控件状态，才允许执行对应字段动作。截图中的“编辑”入口或输入框只证明当前账号看到了编辑权限，不代表字段有可推导的业务值。

## 可验证的页面结构

- “基本信息”包含专利状态、专利号、申请名称、申请类型、申请受理日和授权公告日。
- “技术摘要”有“编辑”入口，进入大文本编辑区域；“预期效益”包含提高效率、提高可靠性、降低能耗等文本框。
- “专利权人”为带新增/删除控件的动态表格；单位名称是可回读的表格列。
- “第一发明人”有人员选择入口；“发明人（含第一发明人）”为带新增/删除控件的动态表格。身份证号、联系方式为可编辑但不属于证书数据。
- “专利权人合并”和“发明人合并”显示为可编辑文本框，内容应由已核对表格派生后再回读。
- “专利出处”包含技术项目名称、技术项目编号、技术项目所属单位、工程项目名称、工程项目编号和其他字段。
- 页面有“申请 PCT 专利数量在 5 件以上”的下拉框，以及经办人、手机、邮箱输入框。
- “补充附件”表格中的既有证书可预览或下载，首版只核验文件存在，不触发上传或删除。

## 权限更新控件矩阵

| 区域 | 已观察到的控件 | 数据来源/自动化边界 |
|---|---|---|
| 技术摘要、预期效益 | 编辑入口、大文本框 | 人工或说明书/业务模板；无来源时只识别，不猜填 |
| 专利权人、发明人 | 新增、删除、行号、名称/身份列 | 证书名单可逐条填充；默认不删除已有行，验证行数和顺序 |
| 第一发明人 | 人员选择入口、身份证号、联系方式 | 姓名来自证书；身份证号/联系方式来自人员主数据或人工 |
| 合并字段 | 专利权人合并、发明人合并输入框 | 由已核对表格派生；人工改写要标记 |
| 专利出处 | 技术/工程项目和其他输入框 | 项目台账或人工；不使用证书字段替代 |
| PCT、经办人 | 下拉框、经办人/手机/邮箱输入框 | 业务规则或本地配置；按文字回读 |
| 页面操作 | 保存、返回 | 保存不自动点击；返回需在单步/人工确认下操作 |
