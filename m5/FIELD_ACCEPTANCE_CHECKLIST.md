# M5 现场验收记录模板

本文件是现场首轮记录模板，不把离线模拟页的结果冒充真实内网证据。每条记录需要用户在现场逐字段复核，并把脱敏报告、标注截图和失败原因放入同一诊断目录。

## 样本覆盖

- [ ] 短名单证书：证书字段逐项复核通过
- [ ] 长名单证书：名单顺序、跨行恢复和动态表格逐项复核通过
- [ ] 联合权利人证书：当前权利人和申请日申请人未混填
- [ ] 扫描证书：OCR 结果逐项复核，低置信度字段已人工确认

## 权限更新补充项

- [ ] 技术摘要“编辑”入口可识别；进入编辑态后由用户手工输入并回读
- [ ] 专利出处/项目关联区块可识别；空值未被证书标题或专利号猜填
- [ ] 权利人和发明人动态表格可识别；已有行未删除，新增行顺序正确
- [ ] 第一发明人选择器唯一匹配；身份证号和联系方式不进入日志明文
- [ ] PCT 下拉选项按可见文字识别并回读；口径未确认时保持只识别
- [ ] 经办人字段可识别并回读；保存按钮未被程序点击

## 证据文件

- [ ] `field.report.json`
- [ ] 标注截图
- [ ] `diagnostics/manifest.json` 和 `environment.json`
- [ ] `diagnostics/execution.log`
- [ ] `diagnostics/steps/*_detect.json`、`*_result.json`、审核后的截图
- [ ] 现场确认 profile 版本和模板清单版本

如出现失焦、窗口标题不匹配、页面锚点消失、加载/错误/弹窗状态或字段回读不一致，立即停止并保留当前步骤证据；不得继续执行保存、提交、返回或删除。
