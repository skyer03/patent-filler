# M2 网页 profile

`PROJECT_PLAN_M2_PROFILE.json` 是当前 M2 离线仿真页的版本化 profile。它暂时放在项目根目录，便于直接从仓库根目录运行 CLI；正式内网页面接入前应复制为独立版本，并为每个版本维护对应的锚点、控件状态和模板证据。

`intranet_v1.json` 是 M5 现场 runner 使用的独立 profile，带有现场版本和页面指纹元数据。它仍以 OCR/相对锚点为主；真实内网截图审核后，应在同一版本目录登记模板证据，未确认的页面变化必须回到只识别模式。

profile 只描述标签/区块锚点与相对定位规则，不保存固定屏幕坐标。
